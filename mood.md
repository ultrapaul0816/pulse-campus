# Pulse Campus mood

Pulse Campus should feel like a live placement signal room: precise, useful, quietly active, and grounded in real campus outcomes.

## Visual character

- Dark, high-contrast working environment rather than a marketing dashboard.
- Cognavi teal signals live opportunity and action; it is not general decoration.
- The campus radar is the signature element. Supporting UI stays restrained so the radar remains memorable.
- Motion communicates discovery, selection, or state change. Ambient motion pauses when the user is completing a task.

## Avoid

- Generic KPI-card dashboards.
- Multiple simultaneous attention effects.
- Decorative gamification that obscures the next placement action.
- Claims that imply verified identities or employer intent when the prototype only has counts.
